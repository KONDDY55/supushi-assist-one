# スプシアシストOne — CSV変換デモロボ

普段ExcelにCSVデータを貼り付けて加工している作業を、CSVをクラウドのフォルダへアップロードするだけで自動化する。その便利さを体験していただくためのデモロボです。手動でコピー＆ペーストすることなく、変換後のCSVがメール添付で届く体験を提供します。

このデモでは、Googleフォームを提出窓口として、現Excel・変換前CSV・正解となる変換後CSVと変換条件を受け付けます。クラウド上で変換し、正解データとの一致を確認したうえで、結果のCSVをメールでお届けします。

デモで便利さに納得いただけたら、お客様のGoogle Workspace（GWS）環境での本開発へ進むことを想定しています。保存先となるGoogleドライブのフォルダIDや変換条件を設定し、日々のCSV変換作業のクラウド化・自動化・効率化を実現していきます。

将来的には、このロボを「スプシアシストOne」の顧客要件定義を自動化する仕組みへと進化させ、提出資料と変換条件をもとに、本開発に必要な要件を整理できるようにする構想です。

## デモを試す

[スプシアシストOne｜デモ受付フォーム](https://docs.google.com/forms/d/e/1FAIpQLSeIek39uhJNZM5DyqXGwWQA8Ix8kjcrMI3ST8nxVOz4CCiylA/viewform)

Googleアカウントでログインし、ご自身の現Excel（.xlsx）・前CSV・正解となる後CSVを提出してください。シート名・列範囲と、前CSV・正解の後CSV・Excelの貼り付け先／出力元それぞれのヘッダーの有無を指定します。行番号の入力は不要です。文字コード・改行コード・BOMの回答は不要です。提出CSVの文字コードは自動判定し、変換後CSVはUTF-8（BOM付き）・Windows向け改行（CRLF）でお届けします。処理が成功し、正解の後CSVと一致すれば、変換後CSVがフォームで自動収集したメールアドレスに添付で届きます。

行は「ヘッダーを除いた最初のデータ行から、対象列がすべて空の最初の行の直前まで」を自動判定します。ヘッダーは1行目として扱います。Excelの貼り付け先が空の場合は、ヘッダーの次の行（ヘッダーなしは1行目）へ貼り付けます。途中の空白行より後にデータがある場合は、取りこぼしを避けるためNGで通知します。

## 動作の流れ

1. フォームでメールアドレスを自動収集し、Excel・前CSV・後CSVと、対象シート名・列範囲・ヘッダーの有無を受け付けます。
2. 回答を提出時刻順に、1件ずつ処理します。
3. ExcelをGoogleスプレッドシートに変換し、前CSVのヘッダーを除いたデータを指定列へ貼り付けます。
4. 再計算後の結果と後CSVを、それぞれヘッダーを除いて行数・列数・全セルの文字列で照合します。空白や先頭ゼロは無視しません。CSVファイルのバイト単位の一致ではありません。
5. 一致すればヘッダーなしの変換後CSVをDriveに保存し、メールへ添付します。使用した入力3ファイルはログフォルダへ移管します。
6. 失敗時はユーザーとオーナーへ別メールを送ります。入力不備には修正・再提出を、システム障害や原因未確定の場合には当方で対応し追って連絡する旨を案内します。

## 検証状況と制約

2026年10月16日、所有者環境でデモデータのフォーム提出から変換・正解照合・移管・添付メールの受信まで確認しました。ローカル自動テストも実装しています。

提出ファイルを特定のデモデータに限定せず、ユーザーが指定した条件で処理します。各ファイル10 MB以内、CSVはデータ9,999行以内が対象です。マクロ・外部接続等は対象外とし、Googleスプレッドシートで再現できない関数や正解CSVとの不一致は、CSVを送らず原因と次の対応を通知します。すべてのExcel関数の互換性を保証するものではありません。メール送信にはGoogleの割り当て上限があります。

2026年10月16日、独自データ受付用フォームと送信トリガーの設定完了を確認しました。文字コード等を質問していた方式から、システム側の自動判定・UTF-8出力へ変更しています。利用者側でGASの設定関数を実行する必要はありません。

自動判定の対象はUTF-8／Shift_JISです。判定が曖昧な場合や対象外の形式ではNGとし、CSV UTF-8形式で保存し直す方法をメールで案内します。入力の改行形式は読み込み時に扱い、正解CSVとはファイル形式ではなくデータ内容を照合します。

独自ファイルの受付・条件チェックを含む自動テスト57件に合格しています。独自データでの変換から添付メール受信までの実機テストは、まだ未確認です。
